A small accessibility release.

## ♿ Fixed

**The controls have names now.** Every button carrying an icon and no text — the transport row, eject, open externally, the inline player's play button, the volume slider, the marker flag beside a playlist row — had nothing a screen reader could announce. They carry proper labels now, and the tooltips are unchanged.

Controls that do have visible text, like the playlist rows and the track name, are announced as buttons rather than as plain text, so it is clear they can be clicked. The playlist header reports whether it is open — the same thing its chevron says visually.

**A row could claim a marker it no longer had.** Removing a track's marker cleared the flag icon from its playlist row but left the description behind, so hovering the empty spot still said the track had one.

## 🔧 Under the hood

The project has tests now, run on every push and before a release is created. They bundle the source exactly as it ships and drive it against a stub Obsidian, so what is checked is the file you install. The first suite guards what survives a restart — the class of bug that lost per-track speed and key settings in 1.4.0 and was not caught until 1.4.1.
