## ✨ New

**The keyboard's media keys reach the player.** Play/pause and next/previous track now work without switching to Obsidian first — hit the key while writing in another window and the beat stops. The track also appears in the system's now-playing card, the one Windows slides in with the volume overlay, titled with the track and the note or folder it was picked up from, and its scrubber seeks.

Previous and next are handed over only while there is a playlist to walk, so the system never offers a button that would do nothing. There is a toggle in the settings if another player should keep the media keys.

## 🔍 On the mobile half

This is desktop-only, and not by choice. A plugin can fill the media session in, but something has to carry it to the operating system, and inside Obsidian mobile that is the app's job rather than the page's — so no card appears on the lock screen or in the notification shade. Checked on a device rather than assumed. The plugin fills the session in there anyway, since it costs nothing and cannot misbehave, in case that ever changes; only the setting is hidden, so it stops promising what it cannot deliver.
