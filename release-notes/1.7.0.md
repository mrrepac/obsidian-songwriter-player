## ⌨️ Added

**The numeric keypad runs the player.** `Alt+×` and `Alt+÷` move the key up and down a semitone, `Alt++` and `Alt+−` step the tempo by one bpm — four controls sitting together under one hand, where the old `Alt+PageUp` / `Alt+PageDown` and `Alt+=` / `Alt+-` are spread across the board. Those keep working; the keypad is an addition, not a replacement.

The keypad's plus needed saying out loud, and that is the bug behind this: Obsidian names a key by its key code, and the keypad has its own. Its `+` is a different key from the main row's `=`, so a binding written for `=` never heard it. Its minus, on the other hand, answers to the same name as the main one and worked all along.

## ⚡ Changed

**Turning the built-in hotkeys on takes effect at once.** 1.6.0 made them a setting and then asked for a plugin reload before the setting did anything — so trying a key out cost a restart, and finding out whether it clashed with something cost another. The switch now hands the bindings to the running app: flip it, press the key, done. If a future Obsidian stops offering that, the setting still works and the old "reload first" notice comes back.

## 🧹 Under the hood

All fourteen default bindings live in one table now instead of being spread across fourteen command registrations, and a test guards it: no combination claimed by two commands, a Russian-layout twin for every letter, a modifier on everything. A second command silently answering to a key you already use is the kind of failure nobody reports, because it looks like nothing happening.
