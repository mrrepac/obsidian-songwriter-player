## ⌨️ Changed

**The built-in hotkeys are offered now rather than imposed.** Fourteen commands used to arrive with keys already on them — a single-Alt layout tuned to one person's habits, down to a Russian-layout twin for every letter binding. Whether they are registered at all is a setting now, under a new "Hotkeys" heading.

**Nothing is pulled out from under a vault that already has them.** If the plugin was installed before this release, the setting comes on and every key keeps working exactly as it did. Only a fresh install starts bare — and bare is not the same as unusable: every command is in the command palette, and Obsidian's hotkey settings will bind any of them to anything you like. Your own assignments always beat the plugin's defaults, and that has not changed.

Commands are registered when the plugin loads, so switching this takes effect after the plugin is reloaded. The setting says as much, and a notice repeats it.
