## ✨ New

**Playlists.** A note holding several audio files lines them up as its playlist — and so does a folder: open any audio file and every audio file next to it queues up, sorted the way the file explorer sorts them (`№2` before `№10`), starting on the one you actually clicked.

- **The list lives under the player**, collapsible and remembering whether you left it open. Its heading names the source — the note or the folder — and counts the files.
- **Every row carries its history**: the play counter, and a ⚑ when the track has a marker, so a folder of demos tells you at a glance which ones you have been working on.
- **A click switches tracks without breaking the flow** — if something was playing, the new track keeps playing; a click on the current row is play/pause.
- **`⏮ ⏭` in the transport** walk the list and grey out at its ends, with `Alt+B` / `Alt+N` (and the Russian layout `Alt+И` / `Alt+Т`) doing the same from the keyboard.
- **The list outlives the track**: eject with ⏏ and it stays, so the next take is one click away.
- **Opening a note without audio no longer clears it** — the playlist belongs to the track you are working on, not to the page you happen to be reading, so lyrics and notes can be flipped through while the beats stay queued.

**Drag a track into a note.** Pull a playlist row (or the name of the loaded track) into the editor and an embed of that file lands at the cursor — rendered by this plugin as a waveform player. The link is generated by Obsidian itself, so it follows the vault's link format and path settings.

**Two new settings** under a *Playlist* heading:

- **Whole folder as a playlist** (on) — turn it off to load an opened audio file on its own.
- **Play the playlist through** (off) — when a track ends, the next one starts; the last one simply stops, and a track with an A-B zone keeps looping instead of moving on.

## 🐛 Fixes

- The playlist no longer stops at ~15 rows with empty space below it: the list claims the whole height the player leaves and scrolls inside itself only when it genuinely outgrows the panel, with the waveform and transport staying put.
