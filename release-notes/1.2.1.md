## ⌨️ Changed

**The default hotkeys lost their `Ctrl`.** Transport keys are meant to be hit with one hand while the other one is on the guitar or the mouse, and `Ctrl+Alt+X` is not that. Every default is now a plain `Alt` chord:

| Command | Was | Now |
| --- | --- | --- |
| Play from marker (or from start) | `Ctrl+Alt+X` | `Alt+X` |
| Stop | `Ctrl+Alt+C` | `Alt+C` |
| Set marker at current position | `Ctrl+Alt+A` | `Alt+Z` |
| Play/Pause | `Ctrl+Alt+P` | `Alt+P` |
| Open track's note | `Ctrl+Alt+S` | `Alt+D` |
| Seek back / forward | `Ctrl+Alt+,` / `Ctrl+Alt+.` | `Alt+,` / `Alt+.` |

"Set marker" moved from `A` to `Z` and "open track's note" from `S` to `D` on purpose: `Alt+A` and `Alt+S` are popular editor bindings, while `Z X C` now sit next to each other under the left hand.

Notes:

- **Your own bindings are untouched.** Anything you had rebound in Settings → Hotkeys stays as it is — new defaults only apply to commands you never touched. To pick up the new scheme on a command you had rebound, reset it there.
- **The Russian keyboard layout is still duplicated** for every binding (`Alt+Ч`, `Alt+С`, `Alt+Я`, `Alt+З`, `Alt+В`, `Alt+Б`, `Alt+Ю`).
- **macOS:** Option+letter produces a special character, so plain `Alt` defaults may not fire there — rebind the transport commands to a `Cmd`- or `Ctrl`-based chord in Settings → Hotkeys.
