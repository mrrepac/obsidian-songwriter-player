# Songwriter Player

Плагин для Obsidian: продвинутый аудиоплеер в правой боковой панели для сочинения песен.

Встроенное аудио в Obsidian выгружается при прокрутке заметки, и воспроизведение обрывается. Songwriter держит плеер в отдельной панели: скролль текст сколько угодно — музыка играет. Плеер переживает даже закрытие панели (звук живёт в плагине, а не в интерфейсе).

## Возможности

- **Панель в правом сайдбаре** — открывается кнопкой на ленте (нота) или командой.
- **Подхват из заметки** — плеер сам берёт аудио из открытой заметки (embed `![[song.mp3]]` или ссылка `[[song.mp3]]`). Если музыка уже играет, предлагает переключиться плашкой, не прерывая. Режим настраивается: гибрид / всегда / вручную.
- **Волна трека**:
  - одиночный клик — играть с этого места (клик вне зоны повтора снимает её);
  - двойной клик — поставить маркер;
  - зажать и потянуть — выделить зону A-B;
  - потянуть за границу зоны — подвинуть её (курсор меняется на ↔).
- **Маркер (⚑)** — одна точка на трек: отметь место, с которого продолжаешь работу над песней. «Играть с маркера» всегда начнёт оттуда (а без маркера — с начала). Маркер запоминается для каждого файла, а кнопка ⚑ в строке трека снимает его — она появляется, только когда снимать есть что.
- **Зона повтора (A-B)** — выделенный на волне фрагмент играет по кругу; начало зоны автоматически становится маркером, так что «Играть с маркера» перезапускает зону с начала. Перемотка вручную за пределы зоны не затягивает обратно — луп срабатывает, только когда воспроизведение само дошло до границы B. Зона запоминается для каждого файла; снимается кликом вне зоны или командой Clear A-B loop zone (маркер при этом остаётся). Если зоны только мешают, выключи их в настройках: протяжка по волне перестанет их выделять, сохранённые зоны не применяются, а трек с зоной играет дальше по списку, а не крутится. Ничего не удаляется — включишь обратно, и зоны вернутся.
- **Плейлист** — открыл заметку с несколькими аудиофайлами, и они выстроились в её плейлист; открыл аудиофайл — в плейлист встали все аудиофайлы рядом с ним в папке. Список живёт под плеером (сворачивается и помнит своё состояние): текущий трек подсвечен, у каждой строки — число прогонов и ⚑, если у трека есть маркер, клик переключает на него и не прерывает игру, если что-то играло. `⏮ ⏭` ходят по списку, а сам список остаётся на месте после выгрузки трека — можно выбрать следующий прямо из него. По желанию плейлист играет подряд сам; трек с зоной A-B вместо этого продолжает крутиться.
- **Перетащить трек наружу** — потянул строку (или название загруженного трека) в заметку — вставится ссылка; потянул с зажатым `Alt` — наружу уйдёт сам файл: в проводник, на рабочий стол или в звуковой редактор вроде REAPER, который принимает только настоящий файл на диске, а не виртуальный, какой предлагает обычная браузерная протяжка. `Alt`-протяжка внутрь Obsidian ничего не вставляет — это сознательная цена разделения двух жестов. Нативная передача работает только на компьютере; на мобильном такого пути нет.
- **Порядок плейлиста** — кнопка в шапке списка сортирует его по имени, темпу, числу прогонов или свежести файла; выбранный порядок и есть тот, по которому ходят `⏮ ⏭`, и он запоминается. Только для плейлистов из папки: список, собранный из заметки, идёт в том порядке, какой задала сама заметка.
- **Скопировать трек в открытую заметку** — команда `Copy track to current note` или тот же пункт в меню строки плейлиста по правому клику. Копия ложится в папку вложений хранилища и встаёт в заметку волной; маркер, зона повтора, счётчики и посчитанные темп с тональностью переезжают вместе с ней. Воспроизведение не прерывается — разбор папки не мешает слушать. Если послать тот же трек ещё раз, вставится ссылка на уже лежащую копию, а не второй файл.
- **Счётчик проигрываний и наигранное время** — рядом с названием трека (`▶ 27 · 2ч40м`). Прогон засчитывается, только когда реально наиграно 5 секунд (запустил и сразу остановил — не считается; пауза с продолжением накопление не сбрасывает). Каждый круг зоны повтора — новый прогон. Наигранное время копит только реальное звучание. Правый клик по счётчику — сброс обоих.
- **К заметке трека** — клик по названию трека (или `Alt+D`) возвращает к заметке, из которой подхвачен трек: если она открыта во вкладке — переключение туда, иначе открытие; если источник неизвестен — ищется любая заметка со ссылкой на этот файл.
- **Выгрузить трек** — кнопка ⏏ в строке трека (или команда `Unload track`): плеер очищается и ничего не держит, пока занимаешься другими делами; хоткеи не сработают случайно. Вернуть трек — кнопкой «Взять аудио из заметки» или просто открыв заметку с аудио.
- **Открыть внешне** (перенесено из плагина Open Audio Externally): кнопка ⧉ справа от названия трека в панели и такая же у каждого встроенного аудиоплеера в заметках — клик открывает файл в приложении по умолчанию, правый клик показывает в проводнике. Команды: `Open track in default app`, `Reveal track in system explorer`. Кнопки у встроенных плееров отключаются в настройках.

Маркер и зона видны прямо на волне (оранжевый флажок и подсвеченный фрагмент) — отдельных индикаторов в панели нет. Время, кнопки и громкость — на одной строке под волной.

## Горячие клавиши (по умолчанию)

Все команды переназначаются в Settings → Hotkeys. Русская раскладка продублирована.

| Команда | Клавиши |
| --- | --- |
| Play from marker (or from start) | `Alt+X` |
| Stop (двойное: следующий `Alt+X` сыграет с начала, маркер цел; тройное: удаляются маркер и зона) | `Alt+C` |
| Set marker at current position | `Alt+Z` |
| Play/Pause | `Alt+P` |
| Open track's note | `Alt+D` |
| Seek back / forward | `Alt+,` / `Alt+.` |
| Previous / next track in the playlist | `Alt+B` / `Alt+N` |
| Медленнее / быстрее (шаг — один bpm, тональность на месте) | `Alt+-` / `Alt+=` |
| Транспонировать вниз / вверх на полутон (только ПК) | `Alt+PageDown` / `Alt+PageUp` |
| Играть как записано — и скорость, и тональность | `Alt+0` |

**На нумпаде** все четыре лежат рядом, под одной рукой: `Alt+÷` и `Alt+×` —
тональность вниз и вверх, `Alt+−` и `Alt++` — темп.

Без дефолтных клавиш: Clear marker, Clear A-B loop zone, Load audio from current note, Open player panel, Unload track, Open track in default app, Reveal track in system explorer.

## Настройки

Помимо основных (режим подхвата, шаг перемотки, старт с маркера) есть раздел «Плейлист» (вся папка как плейлист, играть плейлист подряд) и «тонкая настройка»: порог зачёта прогона, окно двойного стопа, высота волны, кнопка у встроенных плееров.

## Данные

Маркеры, зоны повтора и счётчики хранятся в `data.json` плагина по пути аудиофайла; при переименовании файла в хранилище данные переносятся автоматически.

## Сборка

```bash
npm install
npm run build   # tsc typecheck + esbuild → main.js
npm run dev     # watch-режим
```
